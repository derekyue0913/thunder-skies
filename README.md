# 雷霆空战 · Thunder Skies

战争雷霆（街机空战模式）风格的网页游戏原型。单文件、零构建、零安装，浏览器打开 `index.html` 即玩。

![genre](https://img.shields.io/badge/类型-街机空战-orange) ![tech](https://img.shields.io/badge/技术-Three.js%20%2F%20WebGL-blue) ![size](https://img.shields.io/badge/体积-单文件%2033KB-green)

## v2：现代喷气机 + 鼠标操控

- 机型从螺旋桨升级为**现代喷气战斗机**：后掠翼、双外倾垂尾、两侧进气道、加力尾焰随油门变化
- 操控升级为**战雷式鼠标瞄准**：机头追随鼠标指向，自动压坡度，键盘只负责油门与微调
- 速度包线提升至 324 ~ 1224 km/h，交战距离、弹速、AI 节奏同步加快

## 快速开始

- 直接用浏览器打开 `index.html`；或
- 开启 GitHub Pages（Settings → Pages → 部署 `main` 分支根目录）获得在线地址。

## 操作

| 输入 | 功能 |
|---|---|
| 鼠标移动 | 瞄准转向（战雷式，自动压坡度） |
| W / S（或 Shift / Ctrl） | 油门加 / 减 |
| 空格 | 机炮射击 |
| A / D | 滚转微调 |
| Q / E | 方向舵微调 |

## 已实现

- 战雷式鼠标瞄准操控：机头追随鼠标指向，横向偏差自动转为滚转坡度
- 街机飞行模型：油门—速度响应、失速下坠、撞地判定、速度越快转向越灵
- AI 敌机：巡逻 / 追击双状态、前置量瞄准、开火窗口判定、地形回避
- 波次战斗：敌机数量随波次递增（4 → 9），清波奖励
- 战斗反馈：曳光弹、命中火花、爆炸粒子、受击红闪、击杀播报
- HUD：空速 / 高度 / 油门 / 结构强度 / 得分 / 波次 / 剩余敌机 + 鼠标瞄准环
- 程序化音效：喷气引擎呼啸（随油门变调）、机炮、爆炸（WebAudio 合成，无音频资源）
- 程序化世界：FBM 噪声地形 + 顶点着色（沙/草/岩/雪）、湖泊、树林、飘动云层
