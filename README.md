# 雷霆空战 · Thunder Skies

战争雷霆（街机空战模式）风格的网页游戏原型。单文件、零构建、零安装，浏览器打开 `index.html` 即玩。

![genre](https://img.shields.io/badge/类型-街机空战-orange) ![tech](https://img.shields.io/badge/技术-Three.js%20%2F%20WebGL-blue) ![size](https://img.shields.io/badge/体积-单文件%2030KB-green)

## 快速开始

- 直接用浏览器打开 `index.html`；或
- 开启 GitHub Pages（Settings → Pages → 部署 `main` 分支根目录）获得在线地址。

## 操作

| 按键 | 功能 |
|---|---|
| W / S（或 ↑ / ↓） | 俯仰（S 拉杆爬升） |
| A / D（或 ← / →） | 滚转转向（自动协调转弯） |
| Shift / Ctrl | 油门加 / 减 |
| 空格 | 机炮射击 |
| Q / E | 方向舵微调 |

## 已实现

- 街机飞行模型：油门—速度响应、失速下坠、协调转弯、撞地判定
- AI 敌机：巡逻 / 追击双状态、前置量瞄准、开火窗口判定、地形回避
- 波次战斗：敌机数量随波次递增（4 → 9），清波奖励
- 战斗反馈：曳光弹、命中火花、爆炸粒子、受击红闪、击杀播报
- HUD：空速 / 高度 / 油门 / 结构强度 / 得分 / 波次 / 剩余敌机
- 程序化音效：引擎轰鸣（随油门变调）、机炮、爆炸（WebAudio 合成，无音频资源）
- 程序化世界：FBM 噪声地形 + 顶点着色（沙/草/岩/雪）、湖泊、树林、飘动云层
